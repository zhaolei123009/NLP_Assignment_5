# Assignment 5 - Midterm Topics, Sentiment, and Equities

**Start here:** `main.py` runs the project; `results/key_results.csv` contains the
four central sentiment estimates. All documentation and outputs are in English.
The submitted report is unchanged and is not regenerated by this repository.

## Reproduce

Python 3.12+, from this folder:

```bash
python -m pip install -r requirements.txt
python main.py
python -m unittest test_core -v
```

The main run is offline. It recomputes topics, document scores, daily indices,
market/factor residuals, correlations, robustness checks, and forecasts from the
included CSVs. VADER is installed as a normal dependency; library source code is
not copied into this repository. Optional public API adapters are in
`fetch_inputs.py`; newly downloaded records go to `acquired/`, not the frozen data.

source, repeated raw responses, and dozens of auxiliary panels have been removed.

## Principal estimates

The pooled social issue-affect index produces:

| Relationship | n | Pearson r | HAC slope p |
| --- | ---: | ---: | ---: |
| Same-day sweep log-odds change | 103 | -0.026610 | 0.780840 |
| Next-day sweep log-odds change | 101 | +0.031676 | 0.768428 |
| Next-session equal-weight basket abnormal return | 83 | +0.162942 | 0.062549 |
| Next-session directional spread abnormal return | 83 | -0.000275 | 0.932763 |

All four BH q-values are 1.000. The slope p-values, some with lagged controls,
are not simple Pearson correlation-test p-values. Adding sentiment increases
out-of-sample MSE by 1.8% for odds, 6.2% for the equal-weight basket, and 3.3% for
the directional spread. The data do not establish a robust forecasting signal.

The October Reuters/Ipsos registered-voter single-factor priorities are cost of
living 50%, democratic values/norms 25%, immigration 11%, and crime 4% (other 9%,
skipped 1%). The prompted question does not separately rank healthcare or foreign
policy. News coverage and social cluster frequencies are not voter-salience polls.

The conditional equity hypotheses are FSLR benefiting from preservation of
manufacturing credits/trade protection, HCA benefiting from coverage/reimbursement
protection, and GEO facing constraints on detention funding/expansion. These are
policy exposures rather than proven return signs; congressional control does not
replace the president. Company disclosures are linked in `data/sources.json`.

## Definitions that affect interpretation

- Historical observation cutoff: **2026-10-07T23:04:38Z**. This is not a claim
  about code creation or Git commit dates. Actual execution dates and the source
  archive hash are preserved in the metadata.
- The executed estimator is VADER 3.3.2 **issue affect**, not an independently
  validated national-voter or partisan-advantage measure. A negative issue score
  is not automatically pro-Democratic. The original saved archive, supplied
  separately, has different submission-time sentiment execution status.
- The social corpus has 307 electoral-context Hacker News comments; academic
  exam uses of midterm are excluded. The community is not representative of U.S.
  voters. Historical creation time does not prove text was unedited at the cutoff.
- Topic scores use issue-containing sentences. The pooled score uses their union,
  without counting a sentence twice. Daily author means are equally weighted.
  The topic mix can vary; October polling weights are not applied retrospectively.
- Daily signals become available at the next UTC midnight. Missing days stay
  missing and the partial final day is excluded. Stock signals are known by the
  preceding New York equity close. Contract quotes receive a full-bucket embargo.
- The equal-weight basket is one-third each FSLR/HCA/GEO. The directional spread
  is 0.5 FSLR + 0.5 HCA - 1 GEO. Prior-only rolling market models use SPY; robustness
  adds TAN, XLV, and IWM. IWM is a size proxy. These are residual returns, not CAPM
  excess returns or after-cost trading profits. See `data/sources.json` for firm
  policy exposures, contract identifiers, and supporting disclosures.
- HAC requires at least 30 pairs; smaller samples yield descriptive correlations
  only. The conservative sentiment correction family retains all 87 configured
  contrasts/checks. The 20 original odds-equity tests form a separate family.
- Forecasts use expanding windows and training-only scaling. Retrospective topic
  and basket selection, sparse coverage, missing poll/macro controls, and company
  events limit causal and historical trading interpretations.

Key numerical estimates were checked against the larger saved-output package.
The lightweight tests verify timing and missing-data invariants; they do not
measure real political-text classification accuracy.
